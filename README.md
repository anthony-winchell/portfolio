# Portfolio

My personal site, [anthonywinchell.dev](https://anthonywinchell.dev). It's styled
after Neovim with the Dracula theme, and built with Next.js and Tailwind CSS.

## Where things are

| Path                   | What it holds                                               |
| ---------------------- | ----------------------------------------------------------- |
| `src/data`             | Links, projects, and the file list behind the tabs and tree |
| `src/app`              | Pages, metadata, and the social image                       |
| `src/components`       | The editor layout, windows, and command palette             |
| `src/components/demos` | Project previews and interactive demos                      |
| `src/lib`              | Demo logic and keyboard helpers                             |

The TuChat and spotui demos are simulations that follow the real apps' layout
and behavior. They don't connect to anything.
